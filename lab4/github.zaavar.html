GitHub Хуудас ба Repository Нээх Заавар

Энэхүү заавраар GitHub дээр хэрхэн шинэ репозитори үүсгэж, өөрийн хийсэн веб сайтаа интернетэд үнэгүй байршуулах (GitHub Pages) талаар алхам алхмаар суралцах болно.

1. GitHub Бүртгэл Үүсгэх

  • Алхам 1: github.com веб сайт руу орно.
  • Алхам 2: Баруун дээд өнцөгт байрлах Sign up товч дээр дарж, өөрийн имэйл хаяг болон нууц үгээ оруулж бүртгүүлнэ.

2. Шинэ Repository (Төсөл) Үүсгэх

  • Алхам 1: Нүүр хуудасны баруун дээд өнцөгт байрлах "+" тэмдэгт дээр дараад New repository-г сонгоно.
  • Алхам 2: Repository name хэсэгт төслийн нэрээ бичнэ (жишээ нь: web-developmet-lab).
  • Алхам 3: Тохиргоог Public (нээлттэй) хэвээр үлдээнэ.
  • Алхам 4: Create repository товчийг дарж үүсгэнэ.

3. Кодоо GitHub руу Хуулах (Git ашиглан)

VS Code дээр Terminal нээгээд дараах коммандуудыг дарааллан ажиллуулна:

git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/ТАНИЙ-ХЭРЭГЛЭГЧИЙН-НЭР/ТӨСЛИЙН-НЭР.git
git push -u origin main

4. GitHub Pages ашиглан Веб Сайт Байршуулах

  • Алхам 1: GitHub дээрх үүсгэсэн репозиторийнхоо Settings цэс рүү орно.
  • Алхам 2: Зүүн талын цэснээс Pages хэсгийг сонгоно.
  • Алхам 3: Build and deployment хэсгийн Source дээр Deploy from a branch-ийг сонгоно.
  • Алхам 4: Branch хэсэгт main салбарыг сонгож, Save товчийг дарна.
  • Алхам 5: Түр хүлээсний дараа таны веб сайтын холбоос (URL) бэлэн болох ба интернетээс шууд үзэх боломжтой болно.
